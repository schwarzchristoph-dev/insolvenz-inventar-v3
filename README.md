# Insolvenz Inventar V3

Mobile-first Inventarerfassung für Insolvenzbewertungen.

## Funktionen
- Raum bleibt lokal gespeichert, bis er geändert wird
- Mehrfach-Foto-Upload
- Ein Foto kann als eigener Artikel übernommen werden
- KI-Analyse über /api/analyze (benötigt OPENAI_API_KEY in Vercel)
- Inventarliste lokal im Browser
- CSV-Export

Deployment: Vercel, Branch main.
